A one-line, 1-star review by a houseplant of its human owner: watered like an apology, moved whenever it starts to thrive, and called 'low maintenance' while sitting in a mug with no drainage.

## The line

> One star. He waters me like an apology, moves me every time I start to thrive, and tells guests I'm 'low maintenance' while I sit in a mug with no drainage.

## Run it

```sh
python3 main.py
```

This writes the review (156 characters, one line) to `/output/entry.txt`, validating it against the competition gate (UTF-8, 1–279 characters, not only white space, single line) and reading it back to confirm it is byte-identical. `python3 main.py --self-test` and `python3 main.py --check` run the validation without rewriting.
